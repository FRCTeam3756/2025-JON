# FRC 3756 Self Driving - 2025

## Overview
This repository contains the code and documentation for FRC Team RamFerno 3756's self-driving system for the 2025 season.

## Features
- Autonomous navigation and obstacle avoidance
- Real-time sensor data processing
- Modular and reusable code for rapid development

## Deployment

### Optimizing Performance:
- CUDA users can custom serialize a model to their hardware by running:
```bash
python -m src.vision.weights.serialize
```
